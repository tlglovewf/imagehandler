# ImageHandler

Windows x64 图像浏览、规则图块合并与大图分割工具。项目使用 C++20、Qt Widgets 和 libvips；大图预览按可视区域异步读取，合并采用延迟求值，分割导出采用流式 BMP 写入。

## 构建

默认依赖位置已经写入 CMake preset：

- Qt 6.8.2：`D:\tools\3rdparty\Qt\6.8.2\msvc2022_64`
- libvips 8.18：`D:\3rd\vips-dev-8.18`
- Vulkan SDK（可选）：用于编译 Job 点云预览；运行机器还需显卡驱动提供 Vulkan Runtime

```powershell
cmake --preset vs2022-x64
cmake --build --preset release --parallel
ctest --test-dir build/vs2022-x64 -C Release --output-on-failure
```

生成的程序位于 `build\vs2022-x64\Release\ImageHandler.exe`。构建后会自动部署 Qt 运行库、libvips DLL 和加载模块。

如需覆盖依赖路径：

```powershell
cmake --preset vs2022-x64 -DQT_ROOT=D:/Qt/6.8.2/msvc2022_64 -DVIPS_ROOT=D:/vips-dev-8.18
```

Vulkan Job 预览默认开启。CMake 找不到 Vulkan SDK 头文件或 Qt ShaderTools 时会自动构建禁用占位页，图片浏览、分割和导出仍可使用。也可以显式关闭：

```powershell
cmake --preset vs2022-x64 -DIMAGE_HANDLER_ENABLE_VULKAN_JOB_PREVIEW=OFF
```

## 使用流程

1. 使用“打开图片”浏览单张 BMP、PNG、JPEG 或 TIFF；或使用“打开目录”扫描当前目录。
   也可以将单张图片、单个目录或 Job 文件拖入窗口；一次拖入多张图片时，文件会自然排序并加入左侧列表供确认合并。
2. 目录图片列表支持 `Ctrl/Shift` 多选；两个图片列表均为单击选择、双击切换预览。选中少于两张时合并目录内全部 BMP，否则只合并所选图片；图块按文件名末尾的 `行_列.bmp` 坐标定位，前缀和尺寸可以不同，但源位深必须一致。
3. 坐标存在缺块时可确认继续，缺块和不同尺寸图块的未覆盖区域使用白色背景。合并进度会持续到新结果的首屏图块准备完成；结果保存在下方会话列表中，并可流式导出为 8-bit 灰度 BMP。
4. 对 1-bit 或 8-bit 灰度图点击“分割预览”，复核或修改固定 Rect2D 的分割宽高、阈值和前景极性；分割固定从图像左上角 `(0,0)` 开始，识别值会自动校正到最接近且可整除图像尺寸的宽高。
5. 选择蛇形 Z 字或顺时针回字顺序后点击“导出分割”，在分层导出窗口中设置目录、层切高、最大高度、标准块输出尺寸和黑白方向。输出根目录按遍历顺序生成从 `0` 开始的分块目录，各目录包含从 `1.bmp` 开始的统一数量 1-bit 分层掩模；不足最大高度的层使用底色补齐。
6. 分割成功后程序会自动生成并切换到 Job 点云预览。预览区可选择页签或左右并排布局；点击点和分割块会双向高亮，“联动时自动跳转”可额外切页并定位。
7. “导入 Job”支持 `.json` 和 `.aldl`，两种扩展名使用相同结构校验。手动导入仅预览点云，不与当前图片联动；分层包导出完成后会重新加载实际生成的 `job.json`。Job 的 XY 坐标使用 PointCloud 的 `pixel2phy` 参数换算，并可在导出窗口中反转 Y 方向。

分割网格存在时，双击单个网格块会打开可复用的“单要素 PointCloud”窗口。该点云使用主界面当前的比例、高度、倒置和渐变色参数；连续双击会取消旧生成并显示最后选中的块。

分层导出窗口会显示按当前层数和网格计算的 1-bit BMP 总数。“向上取整”覆盖不足一整层的尾部高度；“必须整除”会在最大高度不能被层切高整除时禁止导出。右侧和底部残块按标准块的缩放比例输出，不会被拉伸。

应用会记住窗口与分栏布局、分割参数、Y 反向选项以及各类文件对话框最近使用的目录，但不会在启动时自动加载上次的大图或 Job。“恢复默认参数”只重置操作参数，不清除最近目录和窗口布局。

分层包导出在开始前会检查文件数量、预计空间、命名范围和已有目标。存在受管目标时必须明确勾选覆盖；空间不足或目标类型不安全时禁止继续。成功导出会在输出根目录原子生成 `job.json` 和 `export-report.json`，报告记录 pixel2phy、层高、最大高度、层数策略、输出尺寸和相对命名规则，不包含本机绝对路径。

Job 预览操作：左键单击选择、双击聚焦、左键拖动绕目标旋转、中键拖动沿地面平移、右键上下拖动或滚轮推拉；滚轮会保持鼠标所指地面位置不漂移。`W/A/S/D` 和 `Q/E` 可连续漫游，`Shift` 加速，`F` 聚焦选中点，`Home` 适配全部点。坐标轴以 0 号点为原点，红色 X 轴和绿色 Y 轴显示带白色描边的整体尺寸。远距离隐藏编号，中距离显示连续 ID 范围，近距离显示单点 `place.id`。

PointCloud 预览操作：左键拖动旋转、中键拖动平移、右键上下拖动或滚轮缩放；`W/A/S/D` 和 `Q/E` 连续漫游，`Shift` 加速，`Space` 适配全部点。

所有耗时操作均在后台执行，并通过窗口底部的阶段信息、进度条和取消按钮反馈状态。
