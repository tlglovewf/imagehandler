# ImageHandler

Windows x64 图像浏览、规则图块合并与大图分割工具。项目使用 C++20、Qt Widgets 和 libvips；大图预览按可视区域异步读取，合并采用延迟求值，分割导出采用流式 BMP 写入。

## 构建

默认依赖位置已经写入 CMake preset：

- Qt 6.8.2：`D:\tools\3rdparty\Qt\6.8.2\msvc2022_64`
- libvips 8.18：`D:\3rd\vips-dev-8.18`
- Vulkan SDK（可选）：用于编译 Job 点云预览；运行机器还需显卡驱动提供 Vulkan Runtime

```powershell
cmake --preset vs2022-x64
cmake --build --preset release --parallel
ctest --test-dir build/vs2022-x64 -C Release --output-on-failure
```

生成的程序位于 `build\vs2022-x64\Release\ImageHandler.exe`。构建后会自动部署 Qt 运行库、libvips DLL 和加载模块。

如需覆盖依赖路径：

```powershell
cmake --preset vs2022-x64 -DQT_ROOT=D:/Qt/6.8.2/msvc2022_64 -DVIPS_ROOT=D:/vips-dev-8.18
```

Vulkan Job 预览默认开启。CMake 找不到 Vulkan SDK 头文件或 Qt ShaderTools 时会自动构建禁用占位页，图片浏览、分割和导出仍可使用。也可以显式关闭：

```powershell
cmake --preset vs2022-x64 -DIMAGE_HANDLER_ENABLE_VULKAN_JOB_PREVIEW=OFF
```

## 使用流程

1. 使用“打开图片”浏览单张 BMP、PNG、JPEG 或 TIFF；或使用“打开目录”扫描当前目录。
   也可以将单张图片、单个目录或 Job 文件拖入窗口；一次拖入多张图片时，文件会自然排序并加入左侧列表供确认合并。
2. 目录图片列表支持 `Ctrl/Shift` 多选；两个图片列表均为单击选择、双击切换预览。选中少于两张时合并目录内全部 BMP，否则只合并所选图片；图块按文件名末尾的 `行_列.bmp` 坐标定位，前缀和尺寸可以不同，但源位深必须一致。
3. 坐标存在缺块时可确认继续，缺块和不同尺寸图块的未覆盖区域使用白色背景。合并进度会持续到新结果的首屏图块准备完成；结果保存在下方会话列表中，并可流式导出为 8-bit 灰度 BMP。
4. 对 1-bit 或 8-bit 灰度图点击“分割预览”，复核或修改固定 Rect2D 的分割宽高、阈值和前景极性；分割固定从图像左上角 `(0,0)` 开始，识别值会自动校正到最接近且可整除图像尺寸的宽高。
5. 完成分割后可点击“图元分组”，程序按灰度位深、尺寸和有效像素对单元进行精确分组；图片预览和 Job 坐标使用一致的组颜色。8-bit 全为 `255` 或 16-bit 全为 `65535` 的纯底色块显示为 `x`，不占用普通组编号。分组采用可扩展的比较策略，默认先以 SHA-256 分桶，再逐像素确认，避免哈希碰撞误合并。
6. 选择蛇形 Z 字或顺时针回字顺序后点击“导出分割”，在分层导出窗口左侧设置目录、层切高、最大高度、底座数量、标准块输出尺寸和黑白方向；右侧“导出预览”区同步展示当前活动块（未选择时为第 0 块）的切片缩略图与 3D 堆叠。未选块或只选一块时默认导出全部，多选两块及以上时只导出所选块及其摆放信息。底座数量为 `N` 时，每个图元目录的 `1.bmp`～`N.bmp` 是覆盖最终输出尺寸的纯前景色底图，原切片从 `N+1.bmp` 开始并作为真实层增加模型高度。已分组时每个唯一图元只生成一个从 `0` 开始编号的目录，`job.json` 中不同坐标可重复使用同一 `place.id`；未执行分组时保持每个单元一个目录。
7. 分割成功后程序会自动生成并切换到 Job 预览。预览区可选择页签或左右并排布局；点击点和分割块会双向高亮，“联动时自动跳转”可额外切页并定位。
8. “导入 Job”支持 `.json` 和 `.aldl`，两种扩展名使用相同结构校验，并允许多个 `place` 命令引用同一个 model。Job 同级存在当前版本的 `export-report.json` 和分层切片目录时，会将各模型的 `1.bmp`、`2.bmp` 等切片堆叠后按 Job 坐标实例化，可在连续实体与分层爆炸视图间切换；包不完整时保留坐标点并显示警告。普通手动导入不与当前图片联动；分层包导出完成后会重新加载实际生成的 `job.json`。Job 的 XY 坐标使用 PointCloud 的 `pixel2phy` 参数换算，并可在导出窗口中分别反转物理 X、Y 方向；移动命令默认使用 `relmove`。“以导出范围中心为坐标原点”默认勾选：整图导出按完整分割网格坐标范围的中心计算，多选导出按所有选中分块坐标外接范围的物理中心计算，选中的纯底色块仍参与原点计算，但不生成坐标；取消后，多选块以首个实际导出点为 `(0,0,0)`。导入 Job/ALDL 后，预览以真实 `(0,0,0)` 绘制醒目的坐标原点、方向箭头以及 `+X/-X/+Y/-Y` 标记。`param.txt` 的首项记录最终输出的坐标数量（即 `place` 命令数），不受图元复用影响。
9. 主工具栏的“加工预览”会打开独立的“加工展示”窗口。导入 Job/ALDL 后先显示全部点与序号标签，不显示切片；播放时严格按 `place` 命令顺序累积显示各 model 目录的 `1.bmp`。支持播放/暂停、上一个、下一个和 `1x/2x/4x/8x`；默认每点 1 秒，末点停留，在末点再次播放会清空进度并重播。该窗口使用独立的屏幕坐标系（X 正向向左、Y 正向向下），只改变屏幕显示方向，Job 文件中的坐标值保持不变，也不提供 X/Y 逆向或相对中心点偏移选项；例如 Job 点 `(-45,-45)` 的坐标标签仍显示 `[-45,-45]`。每个 Job 点是对应方块的中心，切片掩膜按方块物理尺寸缩放并居中贴入；掩膜像素行保持 BMP 的原始 Y 顺序，不再映射到几何正 Y 方向，并使用高亮度、高饱和度配色保证在网格上清晰可见。视图仍可旋转、平移和缩放。每个 model 必须有安全的相对目录和 `1.bmp`；`export-report.json` 可选，缺少时按 Job 点距和 BMP 宽高比推断显示尺寸，并在窗口中提示该尺寸非真实物理尺寸。
加工展示在播放期间进行旋转、平移或缩放时只更新相机矩阵；期间新增的掩膜会合并，并在交互结束后一次同步，避免相机被逐点网格上传阻塞。
关闭加工展示窗口会释放已加载的 Job 文档、掩膜、LOD 与 GPU 缓存；下次打开时创建空白的新窗口。

分割网格存在时，双击单个网格块会打开可复用的“单要素 PointCloud”窗口。该点云使用主界面当前的比例、高度、倒置和渐变色参数；连续双击会取消旧生成并显示最后选中的块。

分层导出窗口会显示原切片层数、底座层数、每个图元的总层数和 1-bit BMP 总数；两类层合计最多 1000 层。“向上取整”覆盖不足一整层的尾部高度；“必须整除”会在最大高度不能被层切高整除时禁止导出。Z 偏移默认 `0.001 μm`，首层只包含高度大于该值的像素。导出倍率默认 `13.55`，标准块宽高分别由分割块宽高的像素数乘以导出倍率和“像素到物理”比例后向上取整，结果仍可手动修改；右侧和底部残块会左上对齐补齐到标准块尺寸。默认将每层切片按 X/Y 缩放和中心旋转后居中贴入白色的 `1920 × 1080` 底图；可选 X 方向镜像，顺序为先旋转后镜像。大图底色可独立切换为黑色，也可对最终大图整体执行黑白颠倒。关闭“贴入大图”时直接输出标准块，仍可对标准块执行 X 方向镜像；变换范围超过底图时禁止导出。按 `F` 打开的单元切片预览也提供相同的 Z 偏移设置，并统一作用于缩略图、三维预览和掩模导出。

应用会记住窗口与分栏布局、分割参数、X/Y 反向选项以及各类文件对话框最近使用的目录，但不会在启动时自动加载上次的大图或 Job。“恢复默认参数”只重置操作参数，不清除最近目录和窗口布局。

分层包导出在开始前会按唯一图元数检查文件数量、最终 BMP 尺寸、预计空间、命名范围和已有目标；即使未执行图元分组，也会自动检测并跳过纯底色块，不为其生成切片、模型或打印坐标。存在受管目标时必须明确勾选覆盖；空间不足或目标类型不安全时禁止继续。成功导出会在输出根目录原子生成 `job.json` 和 `export-report.json`，报告记录总摆放数、唯一图元数、复用数、跳过的纯底色块数、pixel2phy、层高、最大高度、层数策略、标准块与底图尺寸、缩放、旋转、采样策略和相对命名规则，不包含本机绝对路径。

Job 预览操作：左键单击选择、双击聚焦、左键拖动绕目标旋转、中键拖动沿地面平移、右键上下拖动或滚轮推拉；滚轮会保持鼠标所指地面位置不漂移。`W/A/S/D` 和 `Q/E` 可连续漫游，`Shift` 加速，`F` 聚焦选中点，`Home` 适配全部点。默认启用“X/Y 逆向”和“相对中心点偏移”：坐标轴、网格、点和模型会作为整体一起翻转或偏移，坐标标签及 Job 数据值始终保持原值；勾选时图片中心显示为 `(0,0)`，取消时以 0 号点为显示原点，X 正方向向左、Y 正方向向下。导出后重新加载 Job 时会把图片中心换算到新的坐标系，避免沿用导出前的旧中心。红色 X 轴和绿色 Y 轴显示带白色描边的整体尺寸。分组后普通点按图元组着色，内部摆放编号用于选择和图片联动，`place.id` 专门表示引用的 model。

PointCloud 预览操作：左键拖动旋转、中键拖动平移、右键上下拖动或滚轮缩放；`W/A/S/D` 和 `Q/E` 连续漫游，`Shift` 加速，`Space` 适配全部点。

所有耗时操作均在后台执行，并通过窗口底部的阶段信息、进度条和取消按钮反馈状态。
